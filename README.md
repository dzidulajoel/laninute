CONFIGURATION_BASE_DONNEES
- host = serveur distant si on est sur un serveur local : localhost ou IP du serveur
- dbname = nom de la base de donnees 
- charset = eviter les problemes de retour de caractere



1- CREATION DE LA BASE DE DONNEES AVEC LA TABLE D'INSCRIPTION
2- CONFIGURATION DE LA CONNEXION AVEC LA BASE DE DONNEES 
3- INSERTION DES DONNEES DE L'UTILISATEUR DANS LA BASE
4- VERIFICATION SI L'UTILISATEUR A RENTREE TOUS LES DONNEES
5- VERIFICATION SI LE NOM D'UTILISATEUR EST UNIQUE
6- VERIFICATION SI LE NOM D'UTILISATEUR ET LE MOT DE PASSE ENTRES SONT IDENTIQUES LORS DE LA CONNEXION 
7- CRYPTAGES DU MOT DE PASSE DANS LA BASE DE DONNEES(PASSWORD_HASH)
8- DECRYPTAGES DU MOT DE PASSE DANS LA BASE DE DONNEES(PASSWORD_HASH)
9- MISE EN PLACE DE LA ZONE ADMIN
